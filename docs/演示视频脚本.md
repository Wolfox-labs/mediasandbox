# MediaSandbox 演示视频 · 演出脚本

> 用途：大赛报名/答辩用的**纯素材**（无旁白、无配乐、无水印），后期自己剪。
> 录制规格：1920×1080 / 30fps / H.264 / 无音轨。
>
> **已按本脚本录完并拼成片**：`video/MediaSandbox-演示素材-当前剪辑.mp4`（03:07，30 个镜头）。
> 实际每个镜头几点开始、多长、建议怎么剪，见 [`素材清单.md`](素材清单.md)。
> 下面是**设计稿**（分镜意图与后期建议）；两者时长对不上时，以素材清单为准。

---

## 0. 这支片子要让人记住的一句话

**"给一句目标，跑出一个能直接交付的产物。"**

不是"又一个能聊天的框"，而是：目标 → 决策 → 真实生成 → 真浏览器验证 → 可下载的网页/海报/幻灯片。
所以全片不展示对话框，只展示**目标怎么变成产物**。

评委在 90 秒内要能回答三个问题，每个问题对应一段画面：

| 问题 | 画面证据 |
|---|---|
| 它到底是干什么的？ | 首页 + 一句话定位（S1） |
| 它凭什么不是套壳？ | 决策层选块的过程、真浏览器点一遍（S2） |
| 产出能看吗？ | 宣传网页滚一遍 + 四档海报（S5） |

## 2. 录制顺序（有依赖，别乱）

1. **先产出**宣传网页（工作台一次真实运行）与宣传海报（画布一次真实运行）。
2. 再录 S2、S3——此时历史里已经有这两次运行，画布「最近运行」和产物页才不会空。
3. S4、S5 最后录，直接引用第 1 步的产物。
4. 每段录完立刻回看首尾帧，别攒到最后一起查。

## 5. 录制纪律（写给自己）

- **不留死等**：一次运行超过 15 秒的空白，停录、跳过、再从结果处续录；后期靠剪辑接。
- **鼠标不做抛物线**：位移用缓动、单次不超过 300ms，不要满屏乱飞。
- **不重复点击**：所有"点了没反应"的瞬间一律重录，剪不出来。
- **每个镜头录两个版本**（一个正常速、一个稍停），后期有挑的余地。
