## 三、建议的剪辑处理

1. **两段长镜头是留给加速的**：`01:35.2` 的节点执行（38.4s）和 `00:35.6` 的决策过程（31.8s）。按 4–6 倍速压到 6–8 秒，配一句旁白正好；素材里的"逐节点亮起"是真实帧，加速后依然清楚。
2. **S5 四张海报是并排对比用的**：四段各 2.6s、构图一致，可以裁成四宫格同时铺开，比顺序播放更有说服力。
3. **片头**：`00:00.0` 那 3.4 秒整屏静止，适合压标题字与 LOGO。
4. **字幕位**：界面底部有一条 `MediaSandbox · MIT · 2026` 页脚，字幕压在画面下三分之一不会挡住内容。
5. **手机宽度那段**（02:49.9）是 390×844 录制、居中补白到 1080p 的，两侧留白可以直接放说明文字。

## 五、素材是怎么录的（要重录时看这里）

录制不是屏幕录制软件，而是 **CDP 逐帧抓取 + ffmpeg 按真实时间戳编码**：画面全部来自真实运行的真实界面，鼠标轨迹做了缓动（人不瞬移），输入是逐字敲的。

```powershell
# 1) 起 headless Edge（CDP 9230）
Start-Process "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" -ArgumentList @(
  '--headless=new','--remote-debugging-port=9230',
  "--user-data-dir=E:\aiPic\通用沙盒基建\.tmp\edge-rec-profile",
  '--window-size=1920,1080','--hide-scrollbars','--disable-gpu',
  '--disable-backgrounding-occluded-windows','--disable-renderer-backgrounding','about:blank')

# 2) 录某一段（S1 / S2 / S3 / S4 / S5 可多选）
cd E:\aiPic\通用沙盒基建\.tmp\rec
node record.mjs S4

# 3) 重新拼成片
cd E:\aiPic\通用沙盒基建\MediaSandbox\video
#    concat.txt 里按顺序列好每个片段，然后：
ffmpeg -y -f concat -safe 0 -i concat.txt -c:v libx264 -preset medium -crf 19 `
  -pix_fmt yuv420p -r 30 -movflags +faststart -an MediaSandbox-演示素材-当前剪辑.mp4
```

脚本本体在 `E:\aiPic\通用沙盒基建\.tmp\rec\`（`lib.mjs` 抓帧与编码、`record.mjs` 各场景、`record-s207.mjs` 单录交互验证）。

踩过的坑，重录时会再遇到：

- **headless 标签页一旦被判成不可见，screencast 就不再出帧**，整段只剩 1 帧（看着像静止画面）。每段录制前先 `Page.bringToFront`。
- **静止画面只产生 1 帧**，所以末帧要按整段真实时长补齐，否则结尾的结论会被切掉。
- **窄窗口录出来是奇数高度**（1000×562），libx264 只收偶数，编码前统一 `scale=trunc(iw/2)*2:trunc(ih/2)*2`。
- 工作台状态存在 localStorage，不先清掉的话会停在上一次的运行上（按钮文案都变了）。

## 六、已知的两处可选优化

1. **S3 段的节点输入显示的是上一次运行的目标**（"校园二手市集"），而画布顶部输入框是"MediaSandbox 参赛宣传海报"。原因是这一段复用了缓存命中的运行。要改需要重录 S3（约 3 分钟 + 一次海报生成）。
2. **S2 决策过程与节点执行没有加速**，成片按真实时长保留，留给后期处理（见第三节）。
