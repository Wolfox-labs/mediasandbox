M5 完成：服务化 + 双 provider 一致性

server 包（Express + WebSocket）：
- REST：提交运行 / 查询状态 / 产物清单 / 产物下载 / 取消 / 工具目录 / 健康检查
- WebSocket：实时推事件，支持只订阅指定 run 并补发历史
- 产物下载按 run 找回沙盒句柄，沙盒销毁后返回 410

服务入口 main.ts：
- provider 可按环境变量选 local 或 docker
- 决策层默认连本地 rizzo-flow，可用桩替代
- 未配置 LLM_API_KEY 时生成式工具不可用，确定性工具仍工作

修复两个真实缺陷：
1. 产物收集把环境预设的空 .gitkeep 当成产物，
   导致「第一个产物」是 0 字节空文件（服务端下载接口被带偏）
   - 新增 isDeliverableArtifact：空文件与占位文件不算产物
2. 组装器把 refine-copy 同时列为通用收尾选项，
   模板路线（不调模型）配上它会因生成层不可用而熔断
   - 收尾候选排除 refine-copy 与 process-image

双 provider 一致性测试（M3/M5 的最终验收）：
- 同一目标在 Local 与 Docker 上产出的文件 SHA-256 逐字节相同
- 计划结构与 provider 无关
- 确定性工具在两个 provider 上都不调用生成层
